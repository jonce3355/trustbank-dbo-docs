Контрагенты

Справочник контрагентов компании: поставщики, покупатели и другие партнёры для быстрого оформления платежей.

Где находитсяИконка «Контрагенты» (люди) во второй позиции левой боковой панели.

Наименования контрагентов на скриншоте заменены на условные подписи «Контрагент N» для защиты персональных данных третьих лиц.

Из чего состоит страница

  • 1
    Кнопка «Создать»Открывает форму добавления нового контрагента (наименование, ИНН/ПИНФЛ, тип, реквизиты).
  • 2
    ПоискИконка лупы для быстрого поиска контрагента по названию или ИНН.
  • 3
    Группы (папки)Контрагентов можно объединять в группы, например «test group», для удобной организации.
  • 4
    Таблица контрагентовСтолбцы: Наименование, ИНН/ПИНФЛ, Тип (Физическое/Юридическое лицо), Статус (Активный/Не активный).

Пошагово

  1. Откройте раздел «Контрагенты» на боковой панели.
  2. Используйте поиск, чтобы найти нужного контрагента.
  3. Нажмите «Создать», чтобы добавить нового контрагента для последующих платежей.
  4. Откройте карточку контрагента для просмотра или редактирования реквизитов.
СоветЗаранее добавленные контрагенты значительно ускоряют оформление регулярных платежей — данные подставляются автоматически.
