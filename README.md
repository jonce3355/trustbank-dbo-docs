# Trustbank DBO Docs

Интерактивная документация (Help Center) по системе дистанционного банковского обслуживания (ДБО) Trustbank Business — для юридических лиц и ИП.

Сайт создан на основе реального исследования интерфейса business.trustbank.uz в безопасном режиме (только просмотр, без изменения данных, отправки платежей или подписания документов). Все персональные данные на скриншотах (ФИО, ПИНФЛ, телефоны, e-mail, номера счетов) замаскированы.

## Структура проекта

Файл index.html — это главная страница Help Center с поиском и карточками всех разделов. Папка assets/css содержит единую стилевую таблицу style.css (тема, layout, аннотации скриншотов, лайтбокс). Папка assets/js содержит main.js — логику поиска по документации, увеличения скриншотов по клику и подсветки активного пункта меню. Папка assets/images содержит скриншоты реального интерфейса с замаскированными персональными данными. Папка pages содержит отдельную HTML-статью для каждого раздела системы: login, dashboard, menu, profile, settings, users, notifications, payments, new-payment, drafts-templates, kartoteka, ept, accounts, credits, deposits, salary, cards, ved, counterparties, petitions, troubleshooting (возможные проблемы и их решение), faq.

## Технологии

Чистый HTML5, CSS3 и JavaScript без фреймворков и сборщиков. Сайт открывается локально прямо из файла index.html, либо публикуется через GitHub Pages.

## Как запустить локально

Скачайте или клонируйте репозиторий, затем откройте файл index.html в любом браузере — установка дополнительного ПО не требуется. Для более стабильной работы навигации и поиска рекомендуется открывать проект через локальный веб-сервер (например расширение Live Server), хотя базовый просмотр работает и при прямом открытии файла.

## Как обновить документацию

Чтобы изменить существующую статью, отредактируйте соответствующий файл в папке pages (или index.html для главной страницы). Чтобы добавить новую статью, скопируйте структуру шапки и бокового меню из любой существующей страницы в pages и заполните раздел article своим содержимым, затем добавьте новый пункт меню во все файлы sidebar и в список SEARCH_DATA внутри assets/js/main.js для корректной работы поиска. После коммита сайт на GitHub Pages обновится автоматически в течение примерно одной минуты.

## Покрытие документации

Разделы Главная, Платежи, Профиль, Все счета, Кредиты, Контрагенты, Настройки компании и Пользователи документированы подробно, со скриншотами реального интерфейса (персональные данные замаскированы). Остальные разделы — Авторизация, Меню, Новый платеж, Черновики и шаблоны, Картотека, Платежные требования, Депозиты, Зарплата, Корпоративные карты, ВЭД, Заявки, Уведомления и FAQ — описаны текстово на основе проведённого исследования интерфейса, без собственных скриншотов.
